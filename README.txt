# Sanharo Coxinhas — Delivery
App web/PWA responsivo para pedidos.

## Antes de publicar
1. Abra `app.js`.
2. Troque `STORE_WHATSAPP` pelo WhatsApp da loja no formato país+DDD+número.
3. Ajuste preços e produtos no array `products`.
4. Ajuste `DELIVERY_FEE` ou implemente taxas por bairro.
5. Publique a pasta em um serviço de hospedagem estática (Vercel, Netlify, GitHub Pages etc.).
6. Gere um novo QR Code usando a URL pública definitiva.

O app envia o pedido para o WhatsApp da loja, mantendo carrinho e funcionando no celular.
